## 🎥 Recording Guide
1. Launch local app or live site: `streamlit run app.py`.
2. Set display resolution to 1920x1080.
3. Use Screen Recording tool (`Cmd + Shift + 5` on macOS) to record 60 seconds matching the timeline above.
4. Save file to `docs/walkthrough_60s.mp4`.
